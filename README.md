# Troca de Valores com Ponteiros em C

## Descrição
Programa desenvolvido em linguagem C para demonstrar a utilização de ponteiros na troca de valores entre duas variáveis.

## Funcionalidades
- Declaração e inicialização de variáveis inteiras.
- Utilização de ponteiros para acessar endereços de memória.
- Troca de valores por meio de uma função.
- Exibição dos valores antes e depois da troca.

## Tecnologias
- Linguagem C
- Biblioteca stdio.h

## Exemplo de execução
```text
Antes da troca: x = 5, y = 10
Depois da troca: x = 10, y = 5
```

## Conceitos abordados
Ponteiros, funções, passagem de endereços de memória e desreferenciação.
